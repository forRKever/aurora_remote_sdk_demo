)

Convert pose covariance to readable format.

This function converts the raw 6x6 covariance matrix to human-readable uncertainty metrics.

The conversion includes computing 95% confidence ellipsoid, 2D radius, and rotation uncertainties.

Parameters
covariance- the raw covariance data
readable_out- the readable values will be stored in this pointer
Returns
the error code
