Detailed Description

The pose covariance readable values structure.

This structure contains human-readable uncertainty metrics extracted from the covariance matrix.

Users can convert the raw covariance matrix to this format using the conversion utility function.

This represents the 3D uncertainty ellipsoid at 95% confidence level.
