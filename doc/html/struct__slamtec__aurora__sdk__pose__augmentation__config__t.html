◆ smoothing_factor

float _slamtec_aurora_sdk_pose_augmentation_config_t::smoothing_factor

Smoothing factor (alpha) for exponential moving average.

Range: 0.0 to 1.0

Higher values = less smoothing (more responsive to new data)

Lower values = more smoothing (smoother but less responsive)

Default: 0.2 (moderate smoothing)
